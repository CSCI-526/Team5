# 本地塔机制试玩版

基于 main `5e5a6e9` 的塔机制与菜单更新。macOS 输出为 `Playtest/Reverse TD - Tower Playtest v6.app`。

## 类型与数值

| 类型 | 配色 | 机制 |
|---|---|---|
| 普通定向 | 保留原色 | 原有定向单体攻击 |
| 镭射 | 红 | 0.8 秒预告后贯穿整条攻击线；每个单位受到同关普通塔 5 倍的伤害（第 2 关 5，第 3 关 7.5，第 4 关 10，第 5、6 关 15，第 7 关 20）；3 秒一个周期；线宽 0.9；延伸到该方向道路尽头，模型朝向同步攻击方向 |
| 四周单体 | 紫 | 方形范围选敌，每次攻击一个单位 |
| 寒冰 | 冰蓝 | 四周单体攻击，伤害与同关四周单体塔一致（第 4 关 2，第 5、6 关 3，第 7 关 4），每秒攻击一次；命中降低移速 25%，持续 2 秒；重复刷新、不叠加；屏障可挡下该次命中及减速 |
| 爆破 | 橙 | 四周选目标，弹丸命中后对目标周围 2×2 方形范围造成与同关四周单体塔相同的伤害；每秒一次；不再对整个射程内所有单位同时攻击 |

现有射程、塔位、HP、占地、奖励和小兵规则优先保留。寒冰统一射程 3.5；镭射射程延伸至该方向道路尽头；后期普通及四周单体塔伤害在第 5、6 关为 3，第 7 关为 4，避免原有高伤害与新机制叠加。减速、预告和冷却随战斗时间推进，暂停不消耗；支持检查点恢复。全部定向塔重新检查道路覆盖，并同步模型炮口、逻辑方向与 preview；不更换模型。传奇冻结会暂停镭射蓄力。

## 开始页

采用用户提供的 REVERSE TD 图片，按原比例显示。PLAY 开始正式流程；LEVELS 显示七关机制介绍；SETTINGS 提供静音与全屏；右上角喇叭可切换静音。LEVELS 是关卡介绍，不跳过正式关卡解锁流程。

## 维护与验证

`Team5.Rebuild.Editor.TowerPlaytestBuild.Prepare` 可重建七关替换配置与配色，并同步 LevelTemplate 的第二座镭射塔。

`Team5.Rebuild.Editor.TowerPlaytestBuild.BuildMac` 构建本地 macOS 试玩包。新增 `TowerVarietyTests` 验证数量、引入顺序、贯穿、减速、暂停及检查点、局部爆炸；`TowerPlaytestPresentationTests` 验证图片、菜单按钮和寒冰预览，生成 `Logs/TowerPlaytestScreens` 截图。

当前数值是首轮试玩起点，尚未完成真人七关通关平衡验证。

## v2 修复

特效使用显式 Resources 材质引用的专用 shader，避免打包剔除。爆破先结算伤害再广播视觉事件；伤害采用 2×2 方形判定，视觉为小型火圈。新增可选 `-tower-smoke` 成品自检参数，在真实打包程序里验证材质、镭射朝向、射程、特效及伤害，不影响普通启动。

## 启动与退出

默认使用原生分辨率的 macOS MaximizedWindow 全屏模式，鼠标移到顶部可呼出系统栏，允许系统切换全屏和调整窗口大小。设置页使用相同的全屏模式。Esc 关闭单位详情或取消技能瞄准；退出程序使用 macOS 系统菜单或 ⌘Q。
