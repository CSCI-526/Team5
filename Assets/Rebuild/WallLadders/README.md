# Scene 1 wall ladders

Scene 1 的 13 段石墙墙顶可行走。上方围墙左侧、中心约 (9, 0.25, 13) 的墙段附带金黄色梯子，入口为 (8.15, 0.25, 13)，墙顶高度为 1.39。

## 游玩

打开 `Assets/Rebuild/Scenes/1.unity` 并 Play。关闭单位检查面板后，左键点击带梯子墙段的顶部：队伍自动走到梯子下方、逐步升到墙顶，再在墙顶排列。
点击连通墙顶可继续移动，点击地面则沿梯子下墙。墙体其他侧面仍阻挡地面单位，无法直接爬墙或跳到孤立的墙顶。
梯子仅供士兵使用，破城车仍走地面。爬升暂时复用现有 Run 动画，没有新制作手脚抓梯子的专用动画。

## 实现

- `WallWalkSurface` 明确描述墙顶高度和梯子端点；墙顶不新增到地面地图编辑格中。
- `LadderWall_3x1.prefab` 保留石墙模型和生命值规则，增加独立梯子静态建模。金属材质为 `LadderMetal.mat`。
- 位置和爬升都由 BattleSimulation 控制，表现层没有插值伪造高度或传送单位。
- 连续导航通过梯子连接不同高度的行走面，同层路径沿用原有连续寻路。途中可重新下达目标。
- 窄墙顶临时排成一列，返回地面时恢复目标站位。MemberId、SlotId 和战斗属性不因登墙改变。
- 墙体摧毁后对应墙顶和梯子失效，位于其上的单位会落回可通行的地面。
- 高度变化时现有 FW 表现仍播放移动动画；暂停时逻辑位置和动画均按原有暂停规则停止。

正式其他关卡没有添加墙顶组件，沿用原来的移动方式；摄像机、地面地图布局及木门规则未修改。
Map Builder 仍按原石墙工具重建地图；若重新应用 Scene 1 地图后需要恢复梯子，可执行 `Team5 > Rebuild > Walls > Add ladder and walkable tops to Scene 1`。
该菜单会备份当前 Scene 1 到 `Logs/WallLadders/`，然后给现有石墙附加墙顶组件，并选择一段有空闲地面入口且位于镜头内部的墙添加梯子。
