# Paint Squad art

Art ported from the owner's own sibling project Paint Squad Wars (`~/TactileWars`, project-owned original art generated by its Blender and editor scripts; fonts are third party SIL OFL 1.1). Everything lives under `Assets/Rebuild/PaintSquad/`. No Paint Squad Wars C# scripts are copied.

## Rebuild

`python3 -I Tools/Rebuild/port_paint_squad_art.py [path/to/TactileWars]` copies every asset below with its `.meta` (import settings, FBX material remaps and GUIDs are kept, so references between the copied assets resolve) and rebuilds the three VFX prefabs. It only reads the source project. Run it with the Team5 editor closed or let the editor reimport afterwards. `PaintSquadAssetTests` (EditMode) checks the result.

## VFX notes

The source prefabs carried `PooledVfx` / `PaintProjectile`. Those components are removed; the particle systems now play on awake and do not loop. Values the removed scripts held, for whoever drives the effects in Team5:

- Muzzle flash: lifetime 0.15 s, one system (`Flash`), not tinted.
- Hit splash: lifetime 0.5 s, systems `Droplets` (tinted with the shooter colour) and `Flash` (not tinted).
- Paintball: a camera-facing `M_Quad` with `M_Team_Red_Dot`; the source script moved it and billboarded it.

In Paint Squad Wars the unit prefab scales the model by 0.9 and places a `BlobShadow` quad (`M_Quad`, `M_BlobShadow`) at y 0.015, scale 0.945, lying flat.
