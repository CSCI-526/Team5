the font files (OFL_LilitaOne.txt, OFL_Fredoka.txt). Downloaded 2026-11-17 from the Google Fonts GitHub

| File | Family | Use | Source | License |
|---|---|---|---|---|
| LilitaOne-Regular.ttf | Lilita One (Juan Montoreano, Reserved Font Name "Lilita") | headings, buttons, numbers | https://github.com/google/fonts/tree/main/ofl/lilitaone | SIL OFL 1.1, unmodified |
| Fredoka-SemiBold.ttf | Fredoka (The Fredoka Project Authors) | body text, labels | https://github.com/google/fonts/tree/main/ofl/fredoka | SIL OFL 1.1, Modified Version |

Fredoka is distributed upstream as a variable font (`Fredoka[wdth,wght].ttf`). This project ships a static
instance at weight 600, width 100, produced with `fontTools.varLib.instancer` (fontTools 4.59.2) so TextMeshPro
renders the SemiBold style. Fredoka declares no Reserved Font Name, so the instance keeps the family name. The
font software is not sold by itself and remains under the OFL.

Derived assets: `LilitaOne SDF.asset`, `Fredoka SDF.asset` (TextMeshPro SDF atlases) and the material presets
`* SDF Outline*.mat` are generated by `TactileWars.EditorTools.FontBuilder` from these files.
